# CSP-S 2026 PRO · 第二轮备考站

> 整合知识点速查 + 代码模板一键复制 + 考试倒计时 + 模拟计时器 + 考场策略

## 功能

- **模板速查** — 30+ C++ 代码模板，覆盖8大分类，一键复制
- **考试倒计时** — 实时显示距 CSP-S 第二轮认证（2026-10-31）的剩余时间
- **模拟计时器** — 3.5小时考试模拟计时，超时变色提醒
- **知识星图** — 全景知识体系，快速定位考点
- **考场策略** — 时间分配、部分分策略、常见错误清单、对拍流程
- **搜索** — 全局搜索模板和知识点
- **快速导航** — 右下角悬浮面板，一键跳转

## 知识分类

| 分类 | 模板数 | 核心考点 |
|------|--------|----------|
| 基础算法 | 7 | 二分、前缀和、差分、BFS/DFS、贪心、离散化 |
| 图论 | 8 | 建图、拓扑排序、并查集、MST、最短路、Tarjan、LCA、差分约束、二分图 |
| 树论 | 4 | 树状数组、线段树、Trie、树链剖分 |
| 动态规划 | 6 | 线性DP、背包、区间DP、树形DP、状压DP、单调队列优化 |
| 数学 | 4 | 快速幂、GCD/扩展欧几里得、素数筛、组合数学 |
| 字符串 | 2 | KMP、字符串哈希 |
| 数据结构 | 3 | ST表、单调栈、优先队列/对顶堆 |
| 考试模板 | 2 | 万能头文件、对拍数据生成器 |

## 技术栈

- 纯静态 SPA，零依赖，零构建
- Hash 路由，数据层 + 逻辑层分离
- 暗色科技风主题（`#0a0f1c` + `#22e6ff`）

## 部署

### GitHub Pages

1. Fork 或上传到 GitHub 仓库
2. Settings → Pages → Source: main branch / root
3. 访问 `https://<username>.github.io/<repo>/`

### 本地运行

直接用浏览器打开 `index.html` 即可。
